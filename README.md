# АСОИУ «Аптека» — Поступление и продажа лекарств

Проект по дисциплине **«Введение в специальность»**.  
Автоматизированная система обработки информации и управления для аптеки: учёт лекарств, поставщиков, склада, сотрудников и кассовых продаж.

---

## Структура проекта

```
├── pharmacy_db.py   — база данных и все функции работы с ней
├── main.py          — главное меню (запускать отсюда)
├── demo.py          — демонстрация всех возможностей БД
├── search.py        — поиск лекарств, сотрудников и поставщиков
├── add_data.py      — добавление данных (вручную или автоматически)
└── delete_data.py   — удаление данных
```

## База данных

Используется **SQLite** (стандартная библиотека Python, файл `pharmacy.db`).

### Таблицы

| Таблица | Описание |
|---|---|
| `medicines` | Каталог лекарств |
| `suppliers` | Поставщики |
| `jnvlp_registry` | Реестр ЖНВЛП с предельными ценами |
| `supply_invoices` | Электронные накладные |
| `warehouse` | Склад: партии по сериям и срокам годности |
| `employees` | Сотрудники (фармацевт, администратор, сисадмин) |
| `sales` | Кассовые чеки |
| `sale_items` | Позиции в чеках |
| `marking_log` | Журнал операций «Честного Знака» / ИС МДЛП |

## Функции

### Автозаполнение тестовыми данными

```python
from pharmacy_db import PharmacyDB, populate_sample_data

db = PharmacyDB()
populate_sample_data(db)  # 12 лекарств, 3 поставщика, 3 сотрудника, 8 продаж
```

### Лекарства

```python
db.add_medicine("Ибупрофен 400мг", "Фармстандарт", "таблетки")
db.get_medicines()
db.search_medicines("парацет", field="name")         # по названию
db.search_medicines("Pfizer", field="manufacturer")  # по производителю
db.search_medicines("таблет", field="dosage_form")   # по форме выпуска
db.search_medicines("да", field="prescription")      # рецептурные
db.search_medicines("ибу", field="all")              # по всем полям
```

### Сотрудники

```python
db.search_employees("Иванова", field="full_name")    # по ФИО
db.search_employees("фармацевт", field="role")       # по роли
db.search_employees("ivanova", field="login")        # по логину
db.search_employees("мария", field="all")            # по всем полям
```

### Поставщики

```python
db.search_suppliers("Фармэкс", field="name")         # по названию
db.search_suppliers("7718830903", field="inn")       # по ИНН
db.search_suppliers("Москва", field="address")       # по адресу
db.search_suppliers("+7", field="phone")             # по телефону
db.search_suppliers("@pharma", field="email")        # по email
db.search_suppliers("москва", field="all")           # по всем полям
```

### Склад и приёмка

```python
invoice_id = db.create_invoice(supplier_id=1, invoice_number="НК-2026-001")
db.receive_goods(invoice_id, medicine_id=1, series="АА1234",
                 expiry_date="2027-12-01", quantity=100,
                 purchase_price=70.0, retail_price=99.0, is_jnvlp=True)

db.get_warehouse()             # остатки (только годные)
db.get_expiring_soon(days=30)  # истекает срок
db.get_low_stock(threshold=10) # малый остаток
db.write_off(warehouse_id=1, quantity=5, reason="expired")
```

### Продажи

```python
sale_id, receipt, total = db.create_sale(
    employee_id=1,
    items=[{"warehouse_id": 1, "quantity": 2}],
    payment_method="card"
)
```

### Отчёты

```python
db.report_revenue("2026-06-01", "2026-06-30")  # выручка по дням
db.report_top_medicines(limit=10)               # топ продаваемых
db.report_expired()                             # просроченные остатки
```

## Добавление данных (`add_data.py`)

Поддерживает два режима для каждого типа записи:

- **Ручное заполнение** — ввод всех полей вручную
- **Автоматическое заполнение** — генерация реальных данных:

| Тип | Источник |
|---|---|
| Сотрудник | [Faker](https://faker.readthedocs.io/) с русской локалью |
| Лекарство | [OpenFDA API](https://open.fda.gov/apis/drug/label/) — более 100 000 препаратов |
| Поставщик | Список реальных российских фармдистрибьюторов |

При автозаполнении лекарства доступен **предварительный просмотр** с выбором варианта:

```
── Оригинал (английский) ─────────────
  Название:      Ibuprofen Tablets
  Производитель: Pfizer Inc.

── Перевод (русский) ─────────────────
  Название:      Таблетки ибупрофена
  Производитель: Pfizer Inc.

Какой вариант добавить?
  1. Английский оригинал
  2. Русский перевод
  3. Отмена
```
